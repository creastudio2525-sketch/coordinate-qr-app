# 座標QRコード作成・読み込みWebアプリ

GitHub にアップロードする静的Webアプリの配布ファイルです。`index.html` と `assets/` を同じ場所に置いて配信してください。

## 内容

- 点名と XYZ 座標から QR コードを作成
- QR コードの読み取りと点名・X・Y・Z の表示
- 平面直角座標系の設定と測地系選択
- Mapbox の地図・航空写真表示、電子コンパス、自己位置計測
- スマートフォン、タブレット、PC の画面に対応

この配布物はビルド済みです。HTML と JavaScript のファイルは編集可能なテキストですが、`.env` などのローカル設定ファイルは含めていません。

## 表示

静的Webホスティングの公開ディレクトリに `index.html` と `assets/` を配置してください。HTTPS で配信すると、カメラと位置情報を使う機能を利用できます。
